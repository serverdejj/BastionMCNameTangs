BASTION MC - BastionMCNameTangs 1.0.4

CAMBIOS:
- Limpieza automatica de hologramas duplicados de versiones anteriores.
- Actualizacion automatica de la linea antigua "Sin clan" para incluir dinero.
- ActionBar sigue intacta sin dinero.
- El dinero usa VaultAPI y necesita un proveedor de economia compatible.

INSTALACION:
1. Compila el proyecto con GitHub Actions.
2. APAGA el servidor completamente (no uses /reload).
3. Elimina TODOS los jars antiguos de BastionMCNameTangs de plugins/.
4. Coloca solo BastionMCNameTangs-1.0.4.jar.
5. Prende el servidor.
6. Si no aparece el dinero, revisa plugins/BastionMCNameTangs/config.yml
   -> nametag.line-three debe tener %money%.
7. Si sale N/D, Vault no encontro un proveedor de economia.

Nota: es posible que otro plugin de TAB/nombres interfiera con las etiquetas.
